Shipgen Designer for Windows (64-bit)
=====================================

Unpack the whole folder anywhere and keep it together: the programs find
their DLLs and the "plugins" folder next to them.

  shipgen-designer.exe   the triangle designer (start this one)
  shipgen-gui.exe        the automatic generator's window
  shipgen-mesh.exe       thin and tidy a 3D model
  shipgen.exe            the command line (run it from a Command Prompt or
                         PowerShell: shipgen.exe --help)

Needs Windows 10 or 11, 64-bit, and a graphics driver with OpenGL 3.3 for
the 3D view. Windows may warn that the program is from an unknown
publisher (it is not signed): choose "More info", then "Run anyway".

This is an alpha, cross-built on Linux and tried under Wine; please report
anything that behaves differently on Windows.

RELEASE_NOTES.txt says what is new. The programs include source from Shores
of Hazeron, copyright Hazeron Freehold LLC, under the licence in
